# MTG Card Dividers

A small, print-focused web app for creating Magic: The Gathering set dividers.

- Searches Scryfall's set catalog and uses official set symbols
- Formats set codes and release dates automatically
- Prints eight 63 × 95 mm dividers on US Letter cardstock in landscape orientation
- Includes dotted cut guides and saves the print queue locally

## Development

The app is a single static file. Open `dist/index.html` directly or serve `dist/` with any local web server.

## Printing

Choose US Letter, landscape orientation, and 100% scale in the browser's print dialog.
